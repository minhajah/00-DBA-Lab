# Enterprise DBA Lab

## Overview

This repository documents the design, implementation, and maintenance of my personal Enterprise Database Administration Lab.

The lab is built using VMware Workstation Pro and is designed to simulate a real-world database environment for learning, testing, and documenting SQL Server, PostgreSQL, Linux administration, automation, backup and recovery, performance tuning, and cloud database technologies.

This repository serves as the foundation for all other database projects in my GitHub portfolio.

---

## Objectives

* Build a professional database administration lab from scratch.
* Learn PostgreSQL administration on Linux.
* Strengthen SQL Server administration skills.
* Practice infrastructure documentation.
* Create reusable deployment and troubleshooting guides.
* Build a portfolio demonstrating hands-on DBA experience.
